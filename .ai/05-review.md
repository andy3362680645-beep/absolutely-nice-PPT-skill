# 05 · 审查验收规范

> 阶段 6 执行规范。审查不是为了追求完美，而是"让好的改进不被形式问题卡住，让真问题不被放过"。
> 采用"改善即批准"原则：分阻塞问题与非阻塞建议，建议不阻塞合入。

## 审查方式

- AI 先按本清单自查，输出 `review.md`（模板见 `templates/review.md`）。
- 报告先给人读：用通俗中文说明成果、最新预览、实际问题和本次需要确认的事项。原始命令、日志、字段与哈希放技术附录或链接，遵守[视觉制作与交付约定](knowledge/visual-workflow.md)。
- 建议另开一个新 AI 会话，只给它 diff 和相关文件，让它做审查，避免"作者自审"放水。
- 推送分支开 PR，人类做意图级审查后合入。

## 第一类：代码检查

### 阻塞问题（必须改）

- 违反 AGENTS.md 铁律、跳阶段、超范围改动。
- 中文文本未走 `src/text_fit.py`，或对中文调用了库自带 `fit_text()`。
- 检查点未实际通过（脚本报错、几何检测溢出、PPT 打不开）。
- 硬编码密钥、个人路径、删除他人文件。
- 影响共用数据结构（大纲/风格参数/manifest）但未同步关联链路。
- 大文件或产物误入 git。

### 非阻塞建议（可后续迭代，记录即可）

- 命名、注释、重复代码、可简化逻辑。
- 更优雅的实现方式。
- 不影响正确性的性能优化。

## 第二类：视觉检查（本项目特有，重点）

对每一页渲染图逐页核对：

- [ ] 内容与 `deck-outline` 一致：无错字、漏字、顺序错误。
- [ ] 文案符合 [文案与来源标注约定](knowledge/content-style.md)：没有无实际作用的免责尾句或生图自行添加的解释；来源可追溯，影响结论的统计口径及“近/超/预计”等必要限定词完整保留。
- [ ] 文字无溢出、无越界、无图文重叠、无遮挡。
- [ ] 字号按[已选场景](knowledge/visual-profiles.json)与实际画布换算核验；标题/分组/正文/来源层级清楚，每页字体≤3款。存储字号与真实导出字号分别核对。
- [ ] 大纲先有内容检索，再有相关主题的网上风格参考；按实际查看范围登记，独立素材生图与最终整页模型协调均有对应记录。
- [ ] 可编辑稿已解决文字堆积、无效空白、图表解释位置与插画主体过小；重点色、字重或荧光底纹适量且可编辑。
- [ ] 文献/学术页按页面任务保留必要概念、方法、证据、解释与条件，无论证跳步或信息过薄；关键分析没有全部藏入备注或在模型美化时被省略，不用字数多少替代判断。
- [ ] 谢谢/交流独立为末页，已计入总页数，与总结、评价及局限分开。
- [ ] 跨宿主检查读取真实PPT及其绑定的对象角色，未知继承、复杂对象与未检查项如实列出；自动结果没有替代视觉/人类验收。
- [ ] 深色底反白文字已加粗一档。
- [ ] 风格与 `style-params` 一致：主色、字体气质、留白比例、装饰元素。
- [ ] 整套 PPT 插画风格统一、与背景和文字协调。
- [ ] 各页主体、产品和构图随内容变化；没有无理由重复同一饮品/点心/场景，用户明确要求的重复除外。
- [ ] 图片实际内容已查看并对应正确商品及时间范围；原图合成、基于原图的模型渲染与概念创作说明准确，模型没有虚构产品配料/切面或冒充现场实拍。
- [ ] v1 与 v2 内容一致。
- [ ] 最终 PNG 有真实模型调用、参考输入、准确文案、提示词和输入/输出哈希；不是把普通导出标成模型重绘。
- [ ] v1 的自动几何/字体核对与最终位图的逐项目视检查分开记录；不把 PDF 检测结果直接当作模型图的检测证明。
- [ ] 模型图中的年份、GO、近/超、数字/单位、来源及已确认的数据摘要完整，无自行改写/去重。
- [ ] 模型图记录真实像素与宽高比、字形可读性；M1 无精确字体/固定像素保证，不用位图推断真实 pt 字号；未进行未经授权的补字、裁切或拉伸。
- [ ] v1 确认、AI 内容初检、最终人类视觉验收分别有据；未获人类验收仍标记等待。
- [ ] 任何自动检测拿不准的地方，人工/AI 视觉复核。

发现问题回到当前页的文案/布局或生图提示词修复，再核对新图；版式普遍问题回改风格参数。M1 仅单页，修改 v1 后人工同步输入再重跑；多页自动定位与局部重绘待 M3 验证。

## 第三类：版权与合规检查

- [ ] 字体全部在 `fonts/README.md` 白名单内，且有授权登记。
- [ ] 参考模板只用于提取风格参数，产物中没有任何参考模板的原图、截图、插画、图形。
- [ ] 背景、插画、装饰均为 AI 重新生成或可商用素材。
- [ ] 使用真实产品照片时，图源、允许用途和署名可追溯；不把公开可访问、人类选图批准或模型重绘当作商用授权。
- [ ] 字体文件未被非法打包分发（遵循各字体授权条款）。
- [ ] 外部链接抓取符合目标平台条款；未验证的抓取方式不用于正式产物（降级为上传截图）。

## 修复闭环

- 阻塞问题在同一分支修复后重新推送，PR 自动更新。
- 修复最多 3 轮；3 轮未过，停止，说明方案级问题，回到阶段 4。
- 合入标准：阻塞项全部清零 + 检查点真实通过 + 视觉检查通过。

## 合入后

- 人类点击合并，删除分支。
- 进入知识蒸馏（`06-retrospective.md`）。
