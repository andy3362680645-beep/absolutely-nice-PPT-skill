# 能力边界（scope）

> 明确 AI 能做什么、必须协同什么、不能做什么。边界不清是 AI 乱承诺、越界操作的根源。

## 能力四象限

| 象限 | 内容 | 处置 |
|---|---|---|
| AI 独立做 | 读代码、写代码、跑脚本、生成大纲草案、提取风格参数、生成素材、组装 v1、渲染、几何检测、视觉初检、写文档 | 按流程自动执行，检查点汇报 |
| AI 辅助人类做 | 内容取舍、商务表达、风格审美、品牌调性判断、排版精修 | 给 2~3 个方案与建议，人类拍板 |
| 人类做 | 需求决策、技术选型确认、确认大纲与风格、审查合入、提供素材与参考、提供生图 API | 人类介入点，AI 不代做 |
| 禁止做 | 直接复制参考模板素材/字体、抓取违反平台条款、伪造数据、跳过检查、自行合入、提交密钥 | 任何情况都不做 |

## 人类的四个必介入点

1. **决策点**：技术选型、渲染路线、是否引入新依赖（人类拍板）。
2. **上下文点**：品牌调性、受众、真实业务数据、参考素材（人类提供，AI 不编造）。
3. **异常点**：spike 失败、平台抓取受阻、3 轮修复未过、出现预期外结果（人类介入，AI 不硬闯）。
4. **验收点**：大纲确认、风格确认、v1 确认、v2 验收、PR 合入（人类确认）。

## 本项目当前明确不做（避免范围蔓延）

- 不做网页版/在线服务；阶段一为本地 Python + 文档/脚本形态。
- 不做 PPT 内容的事实核查与数据真实性担保（内容由用户负责，AI 只做结构与表达）。
- 不做付费字体、不做字体分发。
- 不保证在未验证的平台自动抓取；抓不到就降级为上传截图。
- 不做过度复杂的动画/特效（v1 以静态、清晰、可编辑为目标）。
- 不做非 16:9 的异形画幅（后续可扩展）。

## 禁止事项

- 禁止在未验证版权的情况下把外部素材放进产物。
- 禁止跳过渲染验证直接交付"理论上没问题"的 v2。
- 禁止对用户说"无法完成"却不给出可行替代方案；做不到要说明边界与降级路径。
