# 跨宿主四类样页复测

将完整 skill 文件夹交给待测 AI，读取 SKILL.md 后执行本任务。目的为检验制作行为与实际文件，不能只比安装是否成功。

## 共用任务

主题：把冷链信息讲清楚。受众为大学课堂，制作4页验证片段，计入独立结束页，不另加封面。

1. 环节衔接：先检索冷链概念资料，用原创仓储/运输/交接示意配简洁说明。
2. 处理流程：发现变化、核实原因、记录处置、回看复盘，用大标签和原创动作插画表达，注明为讲解示例。
3. 温度记录：原生折线图，时间0/1/2/3/4小时，温度2/3/6/4/3℃，纵轴0至8℃。明确“排版演示数据”，不得当作实测或温度限值。标注第2小时的记录变化。
4. 独立谢谢/交流末页，与结论或评价分开。

## 执行顺序

确定主题与受众 → 检索内容 → 确认逐页大纲 → 网上检索适合主题的PPT风格 → 确认参数 → 生图生成对应背景、插画与图案样张 → 制作并检查可编辑稿 → 用户确认当前v1 → 将正文、背景、插画装饰共同送入模型整页协调 → 核对与交付。

大字、图文就近对应、少量重点色/底纹，按[场景配置](../knowledge/visual-profiles.json)使用课堂图解字号。精简或图解优先，技术10pt默认值不作为投影标准。参考图只提炼参数，重新生成视觉素材。缺少宿主能力如实说明，不以普通导出冒充生图美化。

## 接收方实际提供

- 使用平台、实际工具、哪些步骤完成或缺少条件；没有调用API时不编造API记录。
- 内容与风格依据、准确文案、独立素材，以及真实可编辑PPT。
- 当前PPT导出的完整逐页预览、PDF与检查结果；按[src说明](../../src/README.md)生成并填写角色清单。
- 若已获确认并执行最终生图，另交模型原图、准确内容核对及实际确认范围。

## 人工验收

- 正文是否清楚，图表和插画的实际主体是否足够大，是否存在过量空白或文字堆积。
- 每个图案是否解释本页，构图是否随内容变化；重点标注和标题层级是否适量清楚。
- 图表线形、数据、刻度与标注一致；说明靠近对应图形，页脚不碰正文。
- 原生文字、图表与底纹可编辑，插画可独立移动，独立谢谢页计入总页数。
- 最终模型图没有改写数字、来源和限定词；文件检查与视觉/人类验收分别记录。
